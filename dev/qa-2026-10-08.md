## Tech Tools

The hub and all 41 guide HTML files were checked for local references. Search now matches multiple words locally without an external AI endpoint. Added three suggested starting routes and a clear 1:1 consultation route.

Corrected text injection in REST, network, Mac/Linux and Helm demos; corrupt/blocked checklist storage; CI/CD completion/reset races; IAM deny logic; touch and keyboard placement; concurrent packet animations; limited GraphQL validation; stale rollback callbacks; misleading simulated metrics. Technical corrections link to primary documentation in the affected pages.

Kubernetes downloads now require explicit dedicated kubeconfig/context. No lab was executed against a real cluster. The incomplete CloudFormation archive is a documented review-only exercise: its launchers cannot create or delete AWS resources. Fixed its broken download link.

Combined release regression run: **48 tests passed** across hub, Tech Tools, affected legacy games and Mist, plus **9 utility regression groups**. Calculator, atlas, AIPost, Liar's Deck, Sugarbox, Password Game and the isolated Nest checks are recorded separately above. All top-level guide scripts parse. **127 local references across 42 HTML files** resolve; repository guardrails and whitespace checks pass.

Browser evidence is a local desktop browser at 390px width, not a physical phone. All local catalogue entries were smoke-checked for rendered content and horizontal overflow; the legacy design archive needed a cache refresh, so its new script includes a compatibility redirect for the old cached entry. REST demo verified literal markup remains text; hub EN/BG/search/empty state and calculator navigation/results were exercised. Full authenticated, multi-device and real-cloud end-to-end checks remain outside this release.
