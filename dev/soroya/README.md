# Soroya project pages

Standalone static project introduction, privacy policy and data-deletion instructions. No JavaScript, forms, analytics, external assets or storage APIs. The original public generated portrait retains its provenance metadata.

- `index.html`: explains the adult fictional AI model and publishing experiment.
- `privacy.html`: project-specific data practices; Meta privacy URL.
- `data-deletion.html`: revocation and operator-assisted deletion; Meta deletion URL.
- `style.css`: shared responsive styles.

Privacy details reflect the current local publishing application, not a public multi-customer service. The legacy app display name is Soraia. Operator contact is the site's established public address. Do not add credentials, private publishing history or machine paths. Review the policy when processing changes.
