# Projects and experiments

Public browser games, practical tools, and independent demos by The Privileged Company.

The hub is `index.html`; technical guides live in `Tech Tools/`. The recipe-book demo lives in `recipes/`. Each larger project documents its own setup.

`nest-quest/` is the English/Bulgarian budgeting RPG: a public landing page, local
play, a fictional demo, and optional existing company-account saves. One Adventure
page features a large reactive fox-dragon, illustrated valley, and shared-fund
display. Income/expense dialogs offer built-in and custom categories, with a fixed
mobile action dock and collapsed history containing monthly category graphs.
Multiple suggested or custom goals share the fund and carry across months;
income builds the world and every expense reverses progress. See its README for
game rules, builds, original artwork provenance, migration, and save boundaries.

Keep personal profiles, private task lists, employer details, and local machine paths out of published files. The hub is public, including pages that request no indexing.
